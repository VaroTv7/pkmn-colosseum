assignment/conversion copies until backend coalescing. `Scalar<s32>` holds
the signed event kind and `Scalar<u32>` the wrapping record byte offset.

the previous eight-byte register-allocation mismatch. Every wrapper value is
assigned before use, and every member operation inlines.

the iteration counter is a **separate `u32`**, so it does not wrap at 127.

retail's signed-byte treatment, not uniquely proven by the literal callsites.

`fn_800FF56C` returns `u32`, `scriptSetEventColID` takes and returns `s32`, and
`fn_800F7434` returns `u32`. Earlier experimental candidates with mismatched
