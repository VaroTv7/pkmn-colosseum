## Source And Compiler Details

- GC/1.3.2 C++ with C linkage preserves the required pool/storage context.
- Unit-level `peephole off` is needed for the prepared combined owner;
  default flags with only the scoped pragmas gave a 1,100-byte save handler.
  An early forward declaration under a scoped pragma did not repair that.
- The save state is s32, initialized before the running flag; the saved flag
  is declared before the result local.
- The previous hero ID is explicitly evaluated before the current hero ID,
  matching retail's call order. Simply reversing the equality operands
  changes that order and is not the accepted solution.
- `backup = (saved = 1, fn_801D036C())` removes the redundant register copy
  without moving the flag initialization past the call.
- First reset-loop locals are destination/index/source. Separate second-loop
  locals are index/source/destination, with source-first setup/increments.
- These settings and shaping choices are explicit byte-match-first
  exceptions in `docs/RULE_EXCEPTIONS.md`, not strict-policy wins.
