## RULE-EXCEPTION applied

- fn_8012F1FC, src/game/hero_move.c. Rule: a local that holds a constant (a
  temporary that only shapes codegen; "named computed values" does not
  cover constants). Form: `HeroMoveNeckMode mode; ... flags |= 1; mode =
  HEROMOVE_NECK_ON; heroMoveSetNeckMode(member, mode);`, tagged
  RULE-EXCEPTION(title-path). The enum typing of neckMode, the mode
  parameter and heroMoveGetNeckMode is plain typing, not an exception.
  Clean fix needed: a natural source for a mode value that the optimizer
  learns only after inlining (B7b's IRO trace: retail keeps the range and
  switch compares but stores li r0,1).
